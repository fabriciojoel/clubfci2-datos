# clubfci2-datos
Datos publicos de https://clubfci2.netlify.app, servidos por GitHub Pages.
No editar a mano: los genera `Publicar datos.bat` desde E:\clubfci2 (build.mjs valida antes de publicar).
- data/*.json: universo de ON/soberanos, emisores, marcas, gobierno, liquidez, montos.
- config/: parametros de calculo (fase 4).
- version.json: cache-busting.
